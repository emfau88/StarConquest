# Sector background prompts

All four source images were generated with OpenAI ImageGen. Runtime versions
are center-cropped to 16:9, resized to 1600 × 900, and exported as WebP by
`assets/source/process_ui_assets.py`.

## Azure Frontier

> Create a polished 16:9 landscape background for a casual sci-fi strategy game sector called “Azure Frontier”. Bright deep-space scene with luminous azure and cyan nebula clouds, sparse tiny stars, a subtle distant blue planet and a few asteroid silhouettes confined to the outer edges. Keep the entire central 70% calm, dark, low-contrast, and uncluttered so colorful game nodes, links, ships, and HUD remain highly readable. Cinematic depth, premium mobile/indie game art, crisp but not noisy, cohesive blue-teal palette. Background art only: absolutely no text, letters, numbers, logos, interface panels, icons, waypoints, ships, star-system markers, borders, or frames.

## Campaign map

> Create a polished 16:9 landscape campaign-map background for a casual sci-fi strategy game. Deep blue and indigo galactic chart with gentle nebula haze, restrained stars, and one elegant luminous route traveling from lower-left toward upper-right. Along that route place exactly five distinct glowing circular destination beacons, no more and no fewer, approximately at these normalized positions: 15% from left / 72% from top, 32% / 58%, 50% / 68%, 68% / 46%, 84% / 28%. The route and beacon glows should be atmospheric guides, leaving room for interactive HTML buttons placed over them. Premium mobile/indie game art, clean, readable, cinematic but not busy. Background only: absolutely no text, letters, numbers, labels, logos, ships, interface frames, buttons, icons, extra waypoints, borders, or panels.
