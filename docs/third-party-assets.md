# Third-party asset licenses

This document records the original source and license for third-party runtime
assets used by StarConquest. It is repository documentation and is not copied
into portal release builds.

## Music

| Runtime file | Original title | Creator | Source | License | Usage |
| --- | --- | --- | --- | --- | --- |
| `public/assets/music/a_chill_fever.mp3` | A Chill Fever (Loopable) | Pro Sensory / Alex McCulloch | [OpenGameArt](https://opengameart.org/content/a-chill-fever-loopable) | [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) | Campaign map and result screens |
| `public/assets/music/chillloopable.mp3` | Chill (Loopable) | Pro Sensory / Alex McCulloch | [OpenGameArt](https://opengameart.org/content/chill-loopable) | [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) | Gameplay |

Both OpenGameArt source pages identify the downloadable MP3 by the same
filename used in this repository and mark it as CC0. Attribution is not
required by CC0; the creator requested credit under the name Alex McCulloch,
which is included here.

## Sound effects

The six files under `public/assets/audio/` are selected from Kenney's
[Sci-fi Sounds](https://kenney.nl/assets/sci-fi-sounds) 1.0 package. The
package contains 70 effects and is released under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

Runtime files:

- `doorClose_001.ogg`
- `doorOpen_001.ogg`
- `forceField_001.ogg`
- `laserLarge_002.ogg`
- `laserRetro_001.ogg`
- `laserSmall_003.ogg`

## Original and generated artwork

The remaining runtime artwork is original project material or was generated
for StarConquest. Reproducible prompts and processing notes are stored beside
the relevant asset families and under the local source-asset archive.
