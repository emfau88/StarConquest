# Runtime background assets

## Legacy source

Generated with the built-in ImageGen workflow on 28 July 2026.

Purpose:

- polished-casual 16:9 runtime battlefield background;
- brighter and friendlier than the original procedural dark-space backdrop;
- quiet central playfield with decorative cyan and violet nebula detail around
  the perimeter.

Final prompt summary:

> Premium bright and friendly 16:9 deep-space battlefield background for a
> polished casual mobile strategy game. Cobalt-blue starfield, cyan nebula on
> the left, violet and magenta wisps on the right, calm lower-contrast center,
> restrained planets and asteroids at the extreme edges. Background only; no
> UI, text, systems, routes, beams or ships.

The original `starconquest-bright-nebula.png` is preserved under
`assets/source/backgrounds/`, but is no longer copied into production because
the three sector backgrounds supersede it.

## Sector backgrounds and campaign map

Generated with the built-in ImageGen workflow on 29 July 2026:

- `sector-azure.webp` for sectors 1–2;
- `sector-quasar.webp` for sectors 3–4;
- `sector-nexus.webp` for sectors 5–6;
- `campaign-map.webp` as the backdrop for the campaign level selector.

All runtime files are 1600 × 900 WebP images. The lossless ImageGen sources,
exact prompts, and processing notes live in
`assets/source/backgrounds/`.
